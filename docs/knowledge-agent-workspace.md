# 本地知识库与角色 Agent

## 使用方式

1. 在知识库选择分类模型并上传文件。任意扩展名可归档，单个文件上限 25MB；本地归档上限 500 个文件、2GB。
2. 原件保存到 `.local-data/knowledge/files/`，文件名是服务端生成的 UUID，不使用上传路径。元数据和已提取正文保存在同目录的 `metadata/` 中；刷新和重启仍可读取。该目录被 Git 忽略，不随代码上传。
3. 支持 UTF-8 文本、JSON、CSV/TSV、PDF 文字层、DOCX、XLSX、PPTX 正文提取。旧 DOC/XLS、图片、音视频、压缩包等仍可保存，但当前不做 OCR、语音识别、压缩包解包或多模态理解。Excel 只读单元格文本及公式缓存值，不执行公式，不识别嵌入图片。
4. 已提取文本交给所选模型分类，得到分类、标题、摘要和标签。分类失败不删除原件，也不生成假分类；可重试或人工修改。分类为模型建议，非正确率保证。
5. 统计和分类图只计真实上传文件；原有 JSON 演示知识单独显示。人工确认分类的正文可被 `searchKnowledge` 检索；私密聊天不要发布到通用检索。
6. 销售助手直接选择产品销售顾问、微信客服、销售复盘或朋友圈运营角色，输入任务并选择最多 5 份知识文件。用户可粘贴或导入个人微信导出的文本，不要求登录 Codex 或购买模型 API。

## 真实边界

- 角色不只是 UI 标签：浏览器提交服务器白名单 `agentRoleId`，服务器解析角色指令并与已开放工具取交集，禁止前端注入提示词、工具、模型地址或文件路径。
- 每次请求独立，不复用浏览器伪造的助手/工具历史。未明确选择客户时不附加演示客户。
- Instant 单次任务与文件正文总字符预算为 4000；思考档位的预算较小，具体见 [推理档位](inference-modes.md)。多文件均分剩余预算。响应 `X-Knowledge-Coverage` 告知每个文件实际纳入字符数和截断状态，页面显示覆盖范围，不能把节选摘要叫做全文复盘。
- 文件正文最多保留 20000 字符用于当前版本解析；原件完整保留。自动分类只用前 4000 字符，并记录分类使用字符数。大批量全文/长聊天分块归纳需要另行扩展，当前不承诺所有长文件一次读完。
- 微信按用户确认采用“个人微信导出记录与文件”。不扫码、不读取微信数据库、不索取密码，不自动回复或发朋友圈。官方微信客服是另一条需企业后台配置的接口路线，不等于个人微信登录。[微信客服官方概述](https://developer.work.weixin.qq.com/document/path/94638)
- 朋友圈 Agent 生成运营计划及文案，销售复盘 Agent 生成事实摘要与行动建议；都不自动写 CRM、联系客户或发布。

## API

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/knowledge` | 读取上传文件、安全元数据和真实分类统计 |
| `POST /api/v1/knowledge` | `multipart/form-data`，`file` + 白名单 `modelProfileId`，归档、解析和分类 |
| `GET /api/v1/knowledge/{id}/download` | 以附件形式下载完整原件，禁止当 HTML 执行 |
| `POST /api/v1/knowledge/{id}/classify` | 用指定模型重试分类 |
| `PATCH /api/v1/knowledge/{id}` | 人工修正标题/摘要/分类，确认或归档 |
| `POST /api/v1/assistant/chat` | 新增 `agentRoleId`、`knowledgeDocumentIds`，流式角色 Agent |

本地知识存储是文件仓库，不是 PostgreSQL 表。业务库存数据仍走原有 PostgreSQL/JSON 数据仓库。现阶段仅监听 `127.0.0.1`，未完成多用户身份权限，禁止直接暴露公网。上传文件未经过杀毒；原件只按附件保存/下载，用户打开未知文件仍需谨慎。

## Qwen3-14B

模型目录新增 `local-qwen3-14b`，实际模型为官方 Ollama `qwen3:14b`，8B 仍为默认。安装命令：

```powershell
npm run local:setup -- --model=14b
```

安装后刷新模型连接即可从界面选择，无须启动第二个 Ollama。约 9GB 权重超过 8GB 显存容量，会使用 CPU/GPU 混合推理；16GB 内存电脑可能较慢或内存不足。

真实模型库存工具验收：

```powershell
npm run verify:local -- --model=14b
node scripts/verify-knowledge-agent.mjs
```

知识验收脚本上传明确命名的虚构测试样本，验证分类、下载字节一致、去重和微信客服角色读取；不读取实际微信聊天。更新代码之后重新构建并重启，浏览器刷新才能看到新页面。
