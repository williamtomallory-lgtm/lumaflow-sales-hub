# 知识库与互联网证据分流

服务端在生成回答前选择 `local`、`web`、`mixed` 或 `direct`。公司库存、发货、交期、报价、天昭产品、用户本地文件和已选资料属于本地证据；机票、天气、新闻等公开时效信息查询互联网。普通计算、写作与代码生成可以直接回答。项目独立记忆范围保持项目内，计划模式不执行查询。

本地问题先运行实际检索，并读取命中文档的正文。已选/分配文件构成严格检索范围；无明确选择时只搜索已人工确认分类的用户文档，以及原有产品与已发布知识。天昭原始导出保留截图/OCR出处及当前选中规格，缺失字段不推断。没有匹配时用不同关键词复查，例如完整的“18W 黑色轨道灯”再查“轨道灯”；词组不会退化为“过道灯”等无关结果。命中部分是节选，无法据此声称读完全部文档。

检索记录以真实工具结果显示在会话中。库存工具使用的正式数据库与演示 JSON、历史小程序截图是不同证据：后两者不能证明今天有货或当天能发，资料不足时必须说明准确 SKU、实时库存及出库截止时间等缺项。互联网不能替代这些私有事实。本地问答不启用网页搜索；混合问题分开报告两类来源，禁止把本地正文或客户/库存数据发送到搜索服务。

生成结束却没有最终答案时，服务端保留工具结果，并以关闭工具的方式重新总结一次，不重复执行写入或搜索。仍然为空则返回已经检索到的证据节选，或明确无法核实的事项。模型失败与“未找到证据”分别处理。

TypeSafe `Choice` 可以参与短任务摘要的语义分流，需服务端明确设置 `TYPESAFE_WORK_ROUTING=true` 与 `TYPESAFE_API_KEY`。私有文件、正文、密钥、路径和检索回执不传给它；库存等明确的本地规则不会被分类器改成联网。置信度低于 0.8 或服务不可用时保留确定性分流。远程实例当前没有配置 Jev 密钥，因此使用本地规则，不能把这称为已连接 TypeSafe 云模型。
