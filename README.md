# LumaFlow Sales Hub

面向照明销售团队的产品知识与资料工作台。首版把最常见的“客户问产品 → 找到准确资料 → 生成可发送内容”流程做成一个无需外部 AI Key 即可完整运行的 MVP。

## 已实现

- 产品中心：结构化管理型号、SKU、参数、材质、颜色、场景、供应商、成本、MOQ、库存与状态
- 智能搜索：支持按 SKU、型号、功率、颜色、材质、品类、使用场景和发货条件组合检索
- 知识问答：只基于已录入产品数据回答；没有匹配依据时明确拒绝编造
- 资料中心：按产品归档图片、参数表、PDF、证书和案例，并支持类型筛选
- 销售资料包：自动生成推荐话术、选择附件、复制话术并下载交付清单
- 产品详情：参数、报价区间、库存交期、适用场景与关联资料统一展示
- 响应式界面：桌面、平板与手机布局
- 诚实的产品边界：客户会话、跟进、正式报价与管理后台标为后续阶段，不伪装成已完成

## 技术栈

- Next.js 16 + React 19 + TypeScript
- 原生 CSS 设计系统

## 首版数据边界

当前目录内的产品、库存与报价都是可替换的演示数据，集中定义在 `src/lib/catalog.ts`。问答与资料包使用同一份数据源，避免不同模块出现互相矛盾的产品信息。

进入生产使用前，应接入真实产品主数据、对象存储、用户权限、消息渠道和价格审批；正式报价不能直接依赖首版中的参考价格区间。

## 路线图

1. 接入真实产品库和资料上传/版本管理
2. 接入客户消息，增加意图识别与人工确认后发送
3. 建立报价价格库、折扣权限、审批和 PDF 版本管理
4. 增加客户上下文、未回复提醒和销售任务
5. 增加权限、知识过期提醒、AI 日志和效果指标
